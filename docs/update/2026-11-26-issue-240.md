# #240 탈퇴 회원 닉네임 노출 · 좋아요 500 오류

## 변경 요약

### 원인
- 탈퇴 신청(DELETED) 회원이 `CommunityProfileInfo.from`에서 `null` 체크만 있어 닉네임·사진이 그대로 노출됨
- 영구 삭제 후 `created_by` 가 null 인 글·댓글에 좋아요 시 `getCreatedBy().getId()`에서 NPE → 500
- 비로그인 + 작성자 null 조합에서 `Objects.equals(null, null) == true` → 비로그인 방문자가 작성자로 처리

### 수정 내용

**`CommunityProfileInfo.java`**
- `from()` 메서드: `user.getStatus() == UserStatus.DELETED`이면 `withdrawn()` 반환
- 탈퇴 신청 직후(유예 중)부터 "탈퇴회원"으로 표시

**`ContentService.java`**
- `toggleLike()`: 좋아요 알림 전송 전 `content.getCreatedBy() != null` null 가드 추가
- 작성자 없는 글에도 좋아요 정상 동작, 알림만 건너뜀

**`CommunityCommentsService.java`**
- `toggleCommentLike()`: `comment.getCreatedBy() != null` null 가드 추가
- `getUserCommentGroups()`: DELETED 회원 조회 시 USER_NOT_FOUND 반환

**`BoardService.java`**
- `increaseView()`, `getById()`: `board.getCreatedBy() != null &&` 조건 추가 — 작성자 없는 글은 누구도 isAuthor = false
- 목록 조회 `toBoardListResponse()`: 동일하게 null 가드 추가
- `getUserBoardList()`: DELETED 회원 조회 시 USER_NOT_FOUND 반환
