# Issue #243 – App Emergency / Maintenance Notice (Bootstrap)

## Summary

Implemented the app emergency/maintenance notice feature for the `/bootstrap/info` endpoint.
Admins can create time-scoped notices (e.g. server maintenance windows, emergency alerts) that
the mobile app displays on startup.

## What Changed

### New Files

| File | Description |
|------|-------------|
| `entity/AppNotice.java` | JPA entity: id, title, body, link, blockApp, startAt, endAt, active, createdAt, updatedAt |
| `repository/AppNoticeRepository.java` | `findCurrentNotice(now)` – JPQL query selecting the active notice in the current time window |
| `dto/AppNoticeInfo.java` | Public DTO returned in the bootstrap response (id, title, body, link, blockApp) |
| `dto/AdminAppNoticeRequest.java` | Request DTO for create/update with Bean Validation |
| `dto/AdminAppNoticeResponse.java` | Full response DTO for admin endpoints including timestamps |
| `service/AppNoticeService.java` | CRUD service: `getCurrentNotice`, `getAllNotices`, `create`, `update`, `delete` |
| `controller/AdminAppNoticeController.java` | `@AdminOnly` controller at `/admin/app-notices` (GET/POST/PUT/DELETE) |

### Modified Files

| File | Change |
|------|--------|
| `controller/BootStrapController.java` | Injected `AppNoticeService`; calls `getCurrentNotice()` and includes result in response; removed debug log and stale `@Slf4j` |
| `dto/BootStrapResponse.java` | Replaced placeholder `String test` field with `AppNoticeInfo notice` (nullable) |
| `global/exception/ErrorCode.java` | Added `APP_NOTICE_NOT_FOUND (404, V0003)` |

## DB Migration (PostgreSQL)

```sql
CREATE TABLE app_notice (
    id          BIGSERIAL PRIMARY KEY,
    title       VARCHAR(100)  NOT NULL,
    body        TEXT          NOT NULL,
    link        VARCHAR(500),
    block_app   BOOLEAN       NOT NULL DEFAULT FALSE,
    start_at    TIMESTAMP     NOT NULL,
    end_at      TIMESTAMP     NOT NULL,
    active      BOOLEAN       NOT NULL DEFAULT TRUE,
    created_at  TIMESTAMP     NOT NULL DEFAULT now(),
    updated_at  TIMESTAMP     NOT NULL DEFAULT now()
);
```

`spring.jpa.hibernate.ddl-auto: update` will create this table automatically on startup
in non-production environments. For production apply the DDL above manually.

## Bootstrap Response Example

```json
{
  "appVersionInfo": { ... },
  "notice": {
    "id": 1,
    "title": "서버 점검 안내",
    "body": "2026-11-27 02:00 ~ 04:00 서버 점검이 예정되어 있습니다.",
    "link": null,
    "blockApp": true
  }
}
```

When no active notice exists, `notice` is `null`.
