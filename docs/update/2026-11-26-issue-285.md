# #285 무효 푸시 토큰 · 같은 기기의 옛 토큰이 지워지지 않음

## 변경 요약

### 원인
`User.appInfos`에 `cascade = ALL` · `orphanRemoval = true`가 설정되어 있는데,
`userAppInfoRepository.deleteAll()`로 삭제를 시도해도 JPA 플러시 시점에
컬렉션에 여전히 남아 있는 엔티티를 Hibernate가 다시 살려 삭제가 취소되는 문제.

### 수정 내용

**`FcmPushService.java`**
- `userAppInfoRepository.deleteAll(unregisteredTokens)` → `user.getAppInfos().removeAll(unregisteredTokens)`
- 컬렉션에서 직접 제거하면 orphanRemoval이 DELETE를 처리하므로 삭제 취소 없음
- `UserAppInfoRepository` 의존성 제거 (더 이상 FcmPushService에서 직접 사용하지 않음)

**`UserService.java`**
- `insertUserAppInfo` 내 `userAppInfoRepository.deleteAll(duplicateDevice)` → `user.getAppInfos().removeAll(duplicateDevice)`
- 같은 기기에서 토큰이 바뀔 때 옛 행이 실제로 삭제됨
